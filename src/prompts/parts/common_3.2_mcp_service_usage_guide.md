### 3.2 MCP Service Usage Guide

MCP tools appear in the API `tools` list when a server is connected. Live server status is in this turn's system context. Use `mcp_query.list_servers` / `mcp_query.get_all_tools` to inspect; `mcp_query.add_server` to add a server without restarting. Full MCP call examples are injected when at least one server is connected.
